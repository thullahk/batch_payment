Batch Payment for Community

Bring Enterprise-grade Batch Payment functionality to Odoo 18 Community Edition. Group payments, reconcile in one click, and streamline your bank operations — all without upgrading.

✓ 100% Free & Open Source (LGPL-3)

Why This Module?

In Odoo Enterprise, Batch Payments let you group multiple customer receipts or vendor payments into a single bank deposit. This module brings that exact same power to Community users running AT Accounting.

📦

Group Payments

Bundle cheques, transfers, or receipts into a single batch before depositing to the bank.

🏦

One-Click Reconcile

Match entire batches against bank statement lines directly from the reconciliation widget.

⚡

Zero Cost

Enterprise-level feature, completely free. LGPL-3 licensed, no hidden charges.

Core Features

📝 Batch Payment Management

Create and manage Inbound (customer receipts) and Outbound (vendor payments) batches with a clean, professional form view:

  • Auto-generated References — Sequence-based naming (BATCH/IN/2024/0001)
  • Payment Method Control — Filter payments by method and journal
  • Status Workflow — Track batches through New → Sent → Reconciled
  • Validation Wizard — Catches errors before submission
  • Chatter Integration — Full audit trail on every batch

🏦 Bank Reconciliation Integration

The crown jewel of this module — a dedicated "Batch Payments" tab inside the AT Accounting bank reconciliation widget:

  • Click-to-Match — Select a batch to instantly match all its payments against a bank statement line
  • Visual Grouping — Shows "Includes X payment(s)" for clear summary
  • Smart Unpacking — Automatically expands batch into individual journal items during validation
  • Quick Navigation — Click batch name to jump directly to the batch record
  • Search & Filter — Filter batches by bank, type, date, and reconciliation status

📊 Complete Batch Lifecycle

Manage all your batches from a clear, organized list view with full status tracking:

  • Color-Coded Status — Instantly see New (blue), Sent (gray), Reconciled (green)
  • Separate Menus — Customer Batch Payments & Vendor Batch Payments under Accounting
  • Activity Tracking — Schedule follow-ups and reminders directly on batches
  • Print & Export — Generate batch payment reports for bank submission
  • Multi-Currency — Full support for batches with different currencies

Additional Highlights

  • ✅ One-Click Batch from Kanban — Select payments → Create batch instantly
  • ✅ Draft Auto-Posting — Draft payments are automatically posted when batch is validated
  • ✅ Duplicate Detection — Prevents same payment from appearing in multiple batches
  • ✅ SEPA Ready — Hooks for SEPA credit transfer file generation
  • ✅ Residual Amount Tracking — Real-time computation of outstanding batch amounts
  • ✅ Security & Access Control — Proper access rights and record rules

How It Works

1️⃣

Register Payments

Record individual customer receipts or vendor payments as usual.

2️⃣

Create Batch

Group payments into a batch — matching what you deposit at the bank.

3️⃣

Validate & Send

Validate the batch. Payments marked as sent. Print or export for the bank.

4️⃣

Reconcile

In bank reconciliation, match the batch in one click — done!
